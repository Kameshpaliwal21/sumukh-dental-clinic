# Sumukh Dental Clinic — Static Website

A responsive static HTML/CSS/JavaScript website for Sumukh Dental Clinic & Implant Center, Indore.

## Files
- `index.html` — website
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and year
- `assets/` — clinic logo and Dr. Shivam Paliwal professional photo

## Deploy on Vercel
1. Create a free account at Vercel.
2. Create a new project and import this folder/repository.
3. For a plain static site, no build command is required.
4. Deploy.
5. Vercel will provide a live `.vercel.app` URL.
6. Later, add your own domain from the Vercel project settings.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders.
3. Ensure `index.html` is at the repository root.
4. Open Settings → Pages and select the publishing source.
5. GitHub Pages will publish the site.

## Important
The site uses only information supplied by the clinic documents/images. Verify all clinical, qualification, publication and contact information before final public launch.

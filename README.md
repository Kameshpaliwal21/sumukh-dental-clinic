# Sumukh Dental Clinic & Implant Center website

Responsive static website inspired by the layout and visual approach of the supplied Smile Path Dental reference, using Sumukh Dental Clinic's own clinic details and assets.

## Deploy
Upload the contents of this folder (index.html, style.css, script.js, assets/) to your Netlify site or GitHub Pages repository. Keep the assets folder alongside index.html.

## Update
- Clinic contact details and hours are in index.html.
- Services and descriptions are in the Services section in index.html.
- Colors, typography and responsive layout are in style.css.
